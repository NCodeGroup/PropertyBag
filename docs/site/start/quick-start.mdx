This page takes you from an empty project to a bag that holds, overrides and removes a value.

## Install

```sh
dotnet add package NCode.PropertyBag
```

The package brings `NCode.PropertyBag.Abstractions` with it. Both share the namespace `NCode.PropertyBag`.

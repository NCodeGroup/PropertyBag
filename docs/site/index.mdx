## Install

```sh
dotnet add package NCode.PropertyBag
```

Code that only passes or reads bags can reference `NCode.PropertyBag.Abstractions` alone. Both packages target net8.0 and net10.0 and are licensed under Apache-2.0.

## At a glance

A key names a value and fixes its type, so the bag hands the value back without a cast.

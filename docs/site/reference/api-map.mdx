## Extension members

`PropertyBagExtensions.SetValue`, `TryAdd`, `GetOrAdd` and `TryRemove`, `ReadOnlyPropertyBagExtensions.TryGetValue`, `GetValue`,
`GetValueOrDefault` and `ContainsKey`, `PropertyBagViewExtensions.CreateChild` and `AsReadOnly`, and `DefaultRegistration.AddPropertyBag`
are declared in C# 14 `extension` blocks and compiled to ordinary static extension methods, so a project on an earlier C# version calls
them the same way, or in their static form, `PropertyBagExtensions.SetValue(bag, timeout)`.
[Name keys after variables](/guides/infer-key-names/) explains how each call names its key.

## Package

```sh
dotnet add package NCode.PropertyBag
```

This package holds the implementation, and depends on `NCode.PropertyBag.Abstractions` and on
`Microsoft.Extensions.DependencyInjection.Abstractions`.

```sh
dotnet add package NCode.PropertyBag.Abstractions
```

This package holds the contracts, for code that only passes or reads bags.

nuget.org lists the target frameworks of each package on its [Frameworks tab](https://www.nuget.org/packages/NCode.PropertyBag#supportedframeworks-body-tab).
